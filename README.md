# Task-Adaptive Physical Reservoir Computing via Tunable Molecular Communication Dynamics

Code and data for the article "Task-Adaptive Physical Reservoir Computing via Tunable Molecular Communication Dynamics" by
Saad Yousuf, Kaan Burak Ikiz, and Murat Kuscu, CALICO Lab, Department of Electrical and Electronics Engineering, Koç University.

Every number and table body of the article and of its Supporting Information is generated by the scripts in `code` from
the files in `data`.

## Contents

- `code`: the Python code.
  - `simulator.py` implements the mean-field model and the stochastic receptor model of the molecular communication
    channel and the ridge-regression readout; `task_data.py` defines the tasks and their data blocks.
  - `search_*.py` run one Bayesian optimization per process, and `launch_*.py` run the searches of the article.
  - `collect_*.py`, `reevaluate_*.py`, and the analysis scripts (reuse, error surfaces, particle validation, robustness,
    readout design, capacity, switching, cell-like readout, echo state network) write the result tables.
  - `make_numbers.py` writes every number and table body of the article as LaTeX macros, and `figures_*.py` and
    `figure_toc_graphic.py` draw the figures.

  The header of each script states its inputs, its outputs, and the settings used in the article.
- `data`: the input sequences of all tasks (`task_inputs`), the results of the particle-based simulations
  (`particle_simulations`), and the results of all optimization runs, with one CSV file per search containing every
  evaluation, together with the collected result tables (`results`).

## Requirements

Python 3.9 with the packages in `requirements.txt` (NumPy 2.0.2, SciPy 1.13.1, Numba 0.60.0, scikit-optimize 0.10.2,
and Matplotlib 3.9.4). The particle-based simulations were run with Smoldyn 2.75.

## Reproducing the numbers, tables, and figures

From the repository folder:

```
pip install -r requirements.txt
python code/make_numbers.py
python code/figures_benchmark_tasks.py
python code/figures_noise_and_task_map.py
python code/figures_case_study.py
python code/figure_toc_graphic.py
```

These scripts read the stored results in `data` and write `numbers.tex`, `tables.tex`, and the figures into the folder
`manuscript`, which is created on the first run. The searches and analyses can be rerun with the scripts in `code`, as
stated in their headers; the stored results were computed with single-threaded numerics, and multithreaded linear algebra
can change the last digits of re-evaluated values.
